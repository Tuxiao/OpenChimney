# Design References

Accepted minimal UI concepts:

- `landing-minimal.png`
- `product-auth-pricing-flow.png`
- `user-console-minimal.png`
- `admin-console-minimal.png`

Implementation rules:

- white or light gray base
- black and gray typography
- thin borders
- compact tables and panels
- restrained green accent
- formal product header/footer for public pages
- no decorative gradients, orbs, nested cards, or marketing dashboard chrome
